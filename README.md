# 🧾 Cuentas Claras

Web para dividir gastos entre amigos, construida con **Spec-Driven Development (SDD)**: primero la spec, después el código. Demo del webinar de [@danielsantos.ai](https://instagram.com/danielsantos.ai), inspirada en [hello-sdd de MoureDev](https://github.com/mouredev/hello-sdd).

```bash
npm install
npm run dev          # http://localhost:5173
npm test
npm run spec:check   # ¿cada requisito tiene su test?
```

## Las fases del webinar (tags de git)
| Tag | Qué hay |
|---|---|
| `inicio` | Proyecto vacío + `AGENTS.md` + plantilla de spec |
| `spec-lista` | Spec con 6 requisitos + plan y tareas |
| `t1-listo` | Tarea 1 hecha (dinero y división) |
| `final` | App completa, tests en verde |

```bash
git checkout spec-lista   # saltar a una fase
git checkout main         # volver al final
```
